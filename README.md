# SMS Spam Classifier 📩

SMS Spam Classifier is a Machine Learning project that classifies SMS messages as Spam or Ham (Not Spam) using Natural Language Processing (NLP) techniques. The project helps in detecting unwanted or fraudulent messages automatically.

🛠️ Tech Stack
- Python
- Machine Learning
- NLP
- Streamlit
- Scikit-learn
- Pandas
- NumPy


📌 Features
- SMS spam detection using ML
- Text preprocessing and NLP techniques
- User-friendly Streamlit interface
- Real-time message prediction
- Fast and accurate classification
